# 微型关系型数据库管理系统 - 实现步骤规划

## 项目概述

**项目名称**：微型关系型数据库管理系统（对标MySQL）  
**开发语言**：C++ 20/23  
**构建工具**：CMake  
**开发环境**：Linux  
**架构模式**：C/S架构（服务器/客户端分离）  

---

## 阶段一：项目准备与环境搭建

### 1.1 开发环境配置
- [ ] 安装Linux开发环境（Ubuntu/Debian推荐）
- [ ] 安装C++编译器（g++ 11+ 或 clang++ 14+，支持C++20/23）
- [ ] 安装CMake（3.20+）
- [ ] 编写`config.md`记录环境配置信息

### 1.2 项目初始化
- [ ] 创建CMake项目结构
- [ ] 创建基础目录结构：
  ```
  project/
  ├── src/
  │   ├── server/          # 服务器端代码
  │   ├── client/          # 客户端代码
  │   ├── common/          # 公共代码
  │   ├── storage/         # 存储引擎
  │   ├── sql/             # SQL解析器
  │   ├── network/         # 网络通信
  │   └── test/            # 单元测试
  ├── include/             # 头文件
  ├── data/                # 数据库存储目录
  ├── CMakeLists.txt       # 主CMake配置
  └── config.md            # 环境配置说明
  ```

## 阶段二：基础组件开发

### 2.1 自定义容器库（核心基础）
> **重要**：不得使用STL标准容器，必须自己实现

- [ ] 实现`Array<T>`（替代std::vector）
  - 动态数组，支持增删改查
  - 迭代器支持
- [ ] 实现`String`（替代std::string）
  - UTF-8编码支持
  - 字符串操作（比较、拼接、截取等）
- [ ] 实现`List<T>`（替代std::list）
  - 双向链表
- [ ] 实现`Map<K,V>`（替代std::map）
  - 键值对存储
- [ ] 实现`Pair<K,V>`
  - 键值对结构

### 2.2 基础工具类
- [ ] 实现`Exception`类（异常处理）
- [ ] 实现`Logger`类（日志记录）
- [ ] 实现`Config`类（配置管理）

## 阶段三：核心数据结构开发

### 3.1 表结构定义
- [ ] 实现`Column`类

- [ ] 实现`Row`类
  - 行的数据容器，包含多个Column
- [ ] 实现`Table`类
  - 表的容器，包含多个Row

- [ ] 实现B+树遍历操作
- [ ] 实现`Index`类封装

### 3.3 数据库类
- [ ] 实现`Database`类
  - 管理多个Table
  - 数据库切换（use命令）

## 关键技术点

### 必须自己实现的组件
1. **所有容器**：Array、String、List、Map等（不能用STL）
2. **B+树索引**：完整的插入、删除、查询操作
3. **SQL解析器**：DDL和DML语句解析
4. **存储引擎**：文件读写、数据持久化
5. **网络通信**：TCP协议、JSON序列化

### 可以使用的第三方库
- 网络库（如Boost.Asio、muduo）
- 多线程库
- 其他基础组件库

### C++标准要求
- 最低C++20
- 尽量使用C++23特性
