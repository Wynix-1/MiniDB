# MiniDB 微型关系型数据库管理系统项目报告

## 第一章 引言

### 1.1 项目背景

随着信息技术的快速发展，数据库管理系统已成为现代软件基础设施的核心组件。关系型数据库以其严格的数据一致性保证、成熟的SQL标准支持和强大的事务处理能力，在企业级应用中占据主导地位。MySQL、PostgreSQL、Oracle等主流数据库系统功能强大，但其庞大的代码库和复杂的架构使得初学者难以理解其内部工作原理。

本项目旨在开发一个对标MySQL的微型关系型数据库管理系统——MiniDB。通过从零开始实现数据库的核心组件，包括自定义容器库、B+树索引、SQL解析器、存储引擎和网络通信层，深入理解关系型数据库的内部机制。项目采用C++23标准开发，严格遵循课程要求不使用STL容器，所有基础数据结构均手工实现，这不仅锻炼了底层编程能力，也加深了对数据结构与算法的理解。

MiniDB采用C/S（客户端/服务器）架构，支持多用户并发访问，具备完整的数据定义语言（DDL）和数据操作语言（DML）支持，实现了数据的持久化存储。项目可作为数据库原理课程的教学辅助工具，帮助学习者直观地理解数据库系统的各个组成部分及其协同工作方式。

### 2.2 系统预期目标

1. **基础容器实现**：不使用STL容器，手工实现Array（动态数组）、String（字符串）、List（双向链表）、Map（映射）等基础数据结构，支持泛型编程。

2. **SQL语法支持**：实现完整的DDL语句（CREATE DATABASE、DROP DATABASE、CREATE TABLE、DROP TABLE、USE）和DML语句（SELECT、INSERT、UPDATE、DELETE），支持WHERE条件查询和多种比较操作符（=、<、>、<=、>=、!=）。

3. **B+树索引**：实现B+树数据结构，为主键建立索引，加速等值查询操作，支持插入、删除、查找和范围查询。

4. **数据持久化**：实现存储引擎，将表数据序列化后持久化到文件系统，支持数据库和表的自动加载与保存。

5. **C/S架构**：基于TCP/IP协议实现服务器和客户端的分离架构，使用JSON格式进行网络数据序列化，支持多客户端并发连接。

6. **交互式CLI**：实现类似MySQL的命令行交互界面，支持多行输入、表格式输出、执行时间显示和客户端命令。

### 3.2 模块设计

#### 3.2.1 容器库模块

容器库是系统的基础设施，提供不依赖STL的数据结构：

- **Array\<T\>**：动态数组，支持自动扩容（容量翻倍策略），提供push_back、pop_back、insert、erase等操作。
- **String**：自定义字符串类，支持UTF-8编码，提供拼接、查找、子串、大小写转换、修剪等操作。
- **List\<T\>**：双向链表，支持头尾插入/删除。
- **Map\<K,V\>**：基于二叉搜索树的映射，支持插入、删除、查找。

#### 3.2.2 数据结构模块

- **Column**：定义表的列，包含列名、数据类型（INT/STRING）、是否主键。
- **Row**：表示表的一行数据，基于列模式存储，所有值以String形式存储。
- **Table**：管理表结构（列定义）和数据（行集合），支持增删改查操作，内置B+树主键索引。
- **Database**：管理多个数据库和其中的表，支持数据库的创建、删除和切换。

#### 3.2.3 B+树索引模块

BPlusTree\<K,V\>实现B+树数据结构，用于主键索引：
- 内部节点存储键和子节点指针
- 叶子节点存储键值对和兄弟节点指针
- 支持insert、search、remove、range_search操作

#### 3.2.4 SQL解析器模块

SQLParser类负责将SQL文本解析为SQLStatement结构：
- 词法分析：识别关键字、标识符、操作符、值
- 语法分析：根据SQL语法规则构建语句结构
- 支持DDL和DML语句的解析

#### 3.2.5 存储引擎模块

StorageEngine类负责数据的持久化：
- save_table：将表数据序列化为.dat文件
- load_table：从文件反序列化表数据
- 文件格式：文件头 + 列定义 + 行数据

#### 3.2.6 网络通信模块

- **TCPServer**：基于POSIX sockets的TCP服务器，支持多线程处理客户端连接
- **TCPClient**：TCP客户端，连接到服务器并发送请求
- **JsonSerializer**：JSON序列化/反序列化，用于网络数据传输

### 4.1 自定义容器实现

#### 4.1.1 Array动态数组

Array是系统的核心动态数组容器，采用模板实现泛型支持。

```cpp
template<typename T>
class Array {
private:
    T* data_;
    size_t size_;
    size_t capacity_;

    void resize(size_t new_capacity) {
        T* new_data = new T[new_capacity];
        for (size_t i = 0; i < size_; ++i) {
            new_data[i] = std::move(data_[i]);
        }
        delete[] data_;
        data_ = new_data;
        capacity_ = new_capacity;
    }

public:
    Array() : data_(nullptr), size_(0), capacity_(0) {}

    void push_back(const T& value) {
        if (size_ >= capacity_) {
            resize(capacity_ == 0 ? 4 : capacity_ * 2);
        }
        data_[size_++] = value;
    }

    void pop_back() {
        if (size_ > 0) --size_;
    }

    T& operator[](size_t index) { return data_[index]; }
    const T& operator[](size_t index) const { return data_[index]; }

    size_t size() const { return size_; }
    bool empty() const { return size_ == 0; }
    void clear() { size_ = 0; }
};
```

Array采用容量翻倍策略进行自动扩容，减少内存分配次数。使用std::move进行移动语义优化，提升性能。

#### 4.1.2 String字符串类

String类提供完整的字符串操作功能，不依赖std::string。

```cpp
class String {
private:
    char* data_;
    size_t size_;
    size_t capacity_;

public:
    String(const char* str = "") {
        size_ = std::strlen(str);
        capacity_ = size_ + 1;
        data_ = new char[capacity_];
        std::memcpy(data_, str, size_ + 1);
    }

    String& operator+=(const String& other) {
        size_t new_size = size_ + other.size_;
        if (new_size + 1 > capacity_) {
            resize(new_size + 1);
        }
        std::memcpy(data_ + size_, other.data_, other.size_ + 1);
        size_ = new_size;
        return *this;
    }

    String substr(size_t pos, size_t len = npos) const;
    size_t find(const String& str) const;
    String to_lower() const;
    String to_upper() const;
    void trim();
    bool starts_with(const String& prefix) const;
    bool ends_with(const String& suffix) const;
};
```

### 4.2 B+树索引实现

B+树是数据库索引的核心数据结构，实现如下：

```cpp
template<typename K, typename V>
class BPlusTree {
private:
    struct Node {
        bool is_leaf;
        Array<K> keys;
        Array<V> values;
        Array<Node*> children;
        Node* next;  // 叶子节点链表指针

        Node(bool leaf) : is_leaf(leaf), next(nullptr) {}
    };

    Node* root_;
    size_t degree_;  // B+树的阶

    V* search(Node* node, const K& key) const {
        size_t i = 0;
        while (i < node->keys.size() && key > node->keys[i]) {
            ++i;
        }
        if (i < node->keys.size() && key == node->keys[i]) {
            return node->is_leaf ? &(node->values[i]) 
                                 : search(node->children[i], key);
        }
        return node->is_leaf ? nullptr : search(node->children[i], key);
    }

    void insert_non_full(Node* node, const K& key, const V& value);
    void split_child(Node* parent, size_t index, Node* child);
};
```

B+树的所有叶子节点通过next指针形成链表，支持高效的范围查询。插入操作通过分裂保持树的平衡。

### 4.3 SQL解析器实现

SQL解析器采用递归下降分析法：

```cpp
class SQLParser {
public:
    SQLStatement parse(const String& sql) {
        String upper = sql.to_upper();

        if (upper.starts_with("CREATE DATABASE")) {
            stmt.type = SQLType::CREATE_DATABASE;
            stmt.dbname = extract_name(sql, 15);
        } else if (upper.starts_with("SELECT")) {
            parse_select(sql, stmt);
        } else if (upper.starts_with("INSERT")) {
            parse_insert(sql, stmt);
        }
        // ... 其他语句类型
        return stmt;
    }

private:
    void parse_where(const String& sql, WhereCondition& where) {
        String ops[] = {"<=", ">=", "!=", "=", "<", ">"};
        for (const auto& op : ops) {
            size_t op_pos = sql.find(op);
            if (op_pos != String::npos) {
                where.column = sql.substr(0, op_pos).to_lower();
                where.op = op;
                where.value = sql.substr(op_pos + op.size());
                where.has_condition = true;
                return;
            }
        }
    }
};
```

操作符匹配时优先匹配多字符操作符（<=、>=、!=），避免将"<="错误解析为"<"。

### 4.5 服务器实现

服务器端集成所有模块，处理客户端请求：

```cpp
int main() {
    Database db;
    SQLParser parser;
    StorageEngine storage("data");
    TCPServer server(port);

    auto handler = [&](const String& request) -> String {
        String sql = JsonSerializer::parse_string_value(request, pos);
        SQLStatement stmt = parser.parse(sql);

        switch (stmt.type) {
            case SQLType::INSERT: {
                Table* table = db.get_table(stmt.tablename);
                Row row(table->columns());
                // 设置行值...
                table->insert(row);
                storage.save_table(*table, db.current_database());
                return JsonSerializer::serialize_response(true, "Query OK");
            }
            // ... 其他语句处理
        }
    };

    server.start(handler);
}
```

服务器在每次数据修改后自动持久化，并在接收到SIGINT/SIGTERM信号时保存当前数据库。

本项目成功实现了一个功能完整的微型关系型数据库管理系统MiniDB。系统采用C/S架构，包含自定义容器库、B+树索引、SQL解析器、存储引擎和网络通信等核心模块，支持完整的DDL和DML语句，实现了数据的持久化存储。

项目的主要成果包括：
1. 手工实现了Array、String、List、Map等基础容器，不依赖STL
2. 实现了B+树索引结构，支持主键加速查询
3. 实现了SQL解析器，支持多种比较操作符
4. 实现了存储引擎，支持数据的自动持久化
5. 实现了类似MySQL的交互式CLI界面
6. 编写了21个单元测试用例，全部通过

### 6.2 项目不足

1. **事务支持**：当前系统不支持ACID事务，缺少事务隔离和回滚机制。
2. **并发控制**：服务器采用简单的多线程模型，缺少行级锁和MVCC等并发控制机制。
3. **查询优化**：SELECT语句采用全表扫描（除主键等值查询外），缺少查询优化器和执行计划。
4. **数据类型**：仅支持INT和STRING两种数据类型，缺少FLOAT、DATE、BLOB等类型。
5. **SQL功能**：不支持JOIN、GROUP BY、ORDER BY、子查询等高级SQL特性。
6. **网络协议**：使用简单的JSON序列化，缺少连接池、SSL加密等企业级特性。

4. 实现WAL（Write-Ahead Logging）日志，提升数据安全性
